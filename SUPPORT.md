# Support

- Questions about the list, a ranking or a category: open a GitHub issue.
- Want a project added: use the "Add a project" issue template, or send a PR that edits `data/projects.yaml` (see CONTRIBUTING.md).
- Found a wrong star count: do not edit it by hand; the weekly routine refreshes every count from the GitHub API. If it is still wrong after the next Monday, open an issue.
- Problems with the scripts: open an issue with the command you ran and its output.

There is no chat channel. Issues are the only support channel and are answered on a best-effort basis.
